
Aircrack-ng is a complete suite of tools to assess WiFi network security. <br>
It focuses on different areas of WiFi security:<br><br>
Monitoring: Packet capture and export of data to text files for further processing by third party tools<br>
Attacking: Replay attacks, deauthentication, fake access points and others via packet injection<br>
Testing: Checking WiFi cards and driver capabilities (capture and injection)<br>
Cracking: WEP and WPA PSK (WPA 1 and 2)<br><br>
All tools are command line which allows for heavy scripting. A lot of GUIs have taken advantage of this feature. It works primarily on Linux but also Windows, macOS, FreeBSD, OpenBSD, NetBSD, as well as Solaris and even eComStation 2. <br><br>
